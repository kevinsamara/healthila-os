# Identity Domain

## Purpose

Identity Domain bertanggung jawab mengelola seluruh identitas yang digunakan dalam Healthila OS.

## Scope

- Authentication
- Users
- Employees
- Customers
- Suppliers
- Roles
- Permissions

## Out of Scope

- Inventory
- Sales
- Finance
- Fulfillment

## Aggregate Roots

- User
- Employee
- Customer
- Supplier
- Role
