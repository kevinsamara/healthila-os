# Procurement Domain

Procurement mengelola seluruh proses pembelian barang dari supplier.

Workflow

Purchase Requisition
        ↓
Purchase Order
        ↓
Goods Receiving
        ↓
Inventory Lot

Scope

- Purchase Requisition
- Purchase Order
- Goods Receiving
- Purchase Return
- Supplier Invoice (future)

Procurement tidak mengubah stok secara langsung.

Goods Receiving akan menghasilkan Inventory Lot.
